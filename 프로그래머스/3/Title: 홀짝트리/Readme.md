📌 홀짝 트리 (Odd-Even Tree)
📍 문제 설명

루트가 있는 이진 트리 root가 주어집니다.
각 레벨(깊이)별로 다음 조건을 만족하는지 확인하세요:

조건

짝수 레벨 (0, 2, 4, …)
→ 모든 노드 값이 홀수
→ 왼쪽에서 오른쪽으로 값이 엄격히 증가

홀수 레벨 (1, 3, 5, …)
→ 모든 노드 값이 짝수
→ 왼쪽에서 오른쪽으로 값이 엄격히 감소

레벨은 루트가 0레벨입니다.

📈 예시
예시 1
Input: [1,10,4,3,7,9,12,5,3,5,7]
Output: true


설명)
레벨 0: 1 (홀수, 증가 OK)
레벨 1: 10,4 (짝수, 10 > 4)
레벨 2: 3,7,9,12 (홀수, 증가)
레벨 3: 5,3,5,7 (짝수, 감소)
→ 모두 조건 만족

예시 2
Input: [5,4,2,3,3,7,9]
Output: false


설명)
레벨 0: 5 (홀수)
레벨 1: 4,2 (짝수, 4 > 2)
레벨 2: 3,3,7,9 (홀수, 증가이어야 하는데 3 == 3)
→ 조건 위반 → false

🧠 해결 전략

레벨 순회(BFS)를 활용합니다.

레벨 별로 노드 값을 순서대로 모읍니다.

각 레벨의 인덱스가 짝수면 홀수 조건 + 증가 검사,
홀수면 짝수 조건 + 감소 검사를 수행합니다.

하나라도 조건을 위반하면 false 반환.

📌 시간/공간 복잡도
구분	복잡도
시간	O(N)
공간	O(N)

BFS로 모든 노드를 한 번 순회하기 때문입니다.
